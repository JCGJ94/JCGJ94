## 👋 Sobre mí

Desarrollador Full Stack con **orientación backend**. Creo APIs, aplicaciones web y productos digitales que integran IA de forma práctica, aplicando buenas prácticas de arquitectura, autenticación, modelado de datos, testing y despliegue cloud.

Ahora mismo estoy reforzando mi perfil en **backend Python e IA aplicada a producto**: LLMs, agentes, RAG, tool calling y automatización controlada en aplicaciones reales. Uso herramientas de IA para acelerar el desarrollo bajo prácticas como **SDD y TDD**, manteniendo el criterio técnico, la validación y la calidad del código como responsabilidad propia.

> 🎯 **Objetivo:** productos donde la IA forme parte de la arquitectura del sistema y aporte valor real a los usuarios, no un añadido.
